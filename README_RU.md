Программный комплекс для симуляции алгоритмической торговли криптовалютными активами с виртуальным балансом, котировками реального времени и бектестингом торговых ботов.

### Архитектурные особенности:
* **Виртуальная торговая среда:** Симуляция спотового баланса, исполнения ордеров на покупку/продажу и расчет динамического PnL без риска для капитала.
* **Потоковые биржевые данные:** Запрос рыночных графиков и цен активов в реальном времени.
* **Модульная архитектура ботов:** Возможность конфигурирования стратегий автоматического входа и выхода из позиций.
* **Подготовка под Web3:** Архитектурная поддержка привязки криптокошельков для депозитов и вывода средств.

### Стек технологий:
* Python 3.12
* Asyncio / Aiohttp
* Matplotlib (Рендеринг аналитических графиков)
* python-dotenv (Управление секретами)
